QR codes de uso único

Cada QR code abre o jogo para uma pessoa só: no primeiro toque na tela, o código é queimado e quem abrir o mesmo link depois vê “QR code já usado”. Funciona com internet (o jogo confere o código na planilha).

Exportar para o Google Sheets

Os dados já ficam gravados na planilha Google ligada ao jogo (botão “Abrir planilha”, no topo). Para levar um recorte para outra planilha, baixe o CSV (respeita os filtros acima) e, no Google Sheets, use Arquivo › Importar › Fazer upload. Datas no formato AAAA-MM-DD HH:MM:SS e números sem casas decimais, para o Sheets reconhecer em qualquer idioma.
